Vibe Coding / AI Agent / 译文审校场景 / Web Demo

背景

全量人工审校成本高，直接依赖模型判断又存在漏判、误判风险。需要译文把关的团队普遍面临一个矛盾：复核成本与质量风险不可兼得。

主要工作

  • 围绕营销、客服与界面文案的译后审校需求，完成需求拆解、功能定义与 PRD 撰写，梳理从案例提交、质量判断、按需查证到分流处理的审校流程，明确输入字段、处理规则与结果展示内容。
  • 基于前置人机双评结果，结合内容风险与模型可靠性，设计审校分流规则，明确自动通过、抽样复核与人工复核的触发条件。
  • 搭建 Agent 证据查证流程，拆分取证权、判断权与放行权，明确查证触发条件、证据检查标准与工具调用上限，以及证据充分后停止检索并复评术语、证据不足或冲突时转人工的处理规则。
  • 基于真实运行轨迹定位证据重复检索问题，将确定性停止权从模型收回规则层，同一历史案例工具调用由4次降至1次；进一步增加原文术语校验与术语锚定检索，降低自由文本Query导致的查证偏移。
  • 设计案例提交、结果展示与回放交互，前置分流结论与依据，展示证据来源和 Agent 执行轨迹；完成前后端联调、模型 API 接入与部署，支持真实案例回放，实现公开链接访问与 Agent 在线交互的完整闭环。

核心产品决策

根据模型在不同任务上的可靠程度，决定哪些审校结果可以直接采纳，哪些需要查证或人工确认。前置评测发现，高风险术语判断存在明显分歧，因此结合内容风险与评测结果制定分流规则，并对依赖官方用法的术语增加证据查证，使审校结果的处理有据可依。

方案设计与取舍

将自主查证限定在需要外部事实的术语问题上，其余环节采用单次模型判断或规则处理，减少不必要的工具调用。拆分取证权、判断权与放行权，要求检索结果先通过来源与适用范围检查，再用于术语复评，最终由规则决定分流，避免模型自行取证、自行放行。MVP 采用受控的官方来源资料，优先验证证据如何影响判断，暂不扩展开放网络检索。

验证结果与后续迭代

通过真实案例回放，验证了证据充分后复评通过、证据不足后转人工、无需查证等路径。运行中发现，Agent 已获取充分证据却继续检索，最终耗尽预算。据此将停止判断权交给规则，同一案例工具调用由 4 次降至 1 次，并完成后续复评与分流。当前为基于小规模官方来源证据包的英文到简体中文审校原型，已完成案例验证，尚未开展真实用户测试。后续可扩充证据覆盖、引入人工复核反馈，关注安全自动放行率、错误自动放行率、人工复核率与单案例处理时长的数据验证。

评测看板 ↗GitHub 仓库

大模型评测 / 人机双评 / 在线数据看板

背景

内容团队引入大模型审校时，需要判断模型在哪些任务上可靠、哪些仍需人工把关。整体评分难以反映具体场景的误判风险，人机分歧也需要进一步核查依据。

主要工作

  • 基于 MQM 翻译质量框架，定义术语、准确性、本地化与受众适配四个维度及评分标准；构建 94 条可追溯双语语料，按误译后果标注内容风险，选取 15 条开展试跑评测。
  • 采用生成与评审分离设计，对 GPT-4o、Claude、Gemini 三款模型生成的 45 份匿名译文开展人工与 Qwen 独立评分，形成 180 次人机双评；按质量维度与内容风险拆分结果，定位整体人机一致率 95% 下“术语 × 高风险”仅 61% 的薄弱组合。
  • 逐条复核人机分歧，结合外部资料核查术语用法，确认 6 次 AI 无据术语判断与 3 次人工漏检，记录判断依据与评分修订，提炼后续 Agent 的证据查证需求。
  • 将评测结果映射为分级人工介入规则，推演不同规则下的复核量；搭建在线评测看板，支持公开访问链接，集中展示可靠性矩阵、分歧案例与策略依据，数据方法和原始评分记录公开可查看。

核心产品决策

根据模型在不同质量维度与内容风险下的审校表现，确定哪些判断需要人工复核。将评测结果按“质量维度 × 内容风险”拆分，单独识别“高风险术语”薄弱组合，为强制人工核验、抽样复核等规则提供依据；对样本内完全一致的组合仍保留抽检，避免将小样本结果直接视为零风险。

方案设计与取舍

分别定义风险等级与错误严重度：前者衡量具体场景下误译的业务代价，后者评价译文中的实际问题，避免混用两种标准。生成模型与评分模型分离，人工与模型按统一标准独立评分；对分歧引入外部证据复核，同时检查模型误判与人工漏检，保留评分修订依据。

验证结果与后续迭代

分歧复核发现，部分术语判断缺少充分的外部依据，推动后续 Agent 引入证据查证。按试跑规则离线推演，人工介入量约为 28/180（15.5%），该比例按维度判断次数计算，不代表线上案例复核率或业务收益。当前结果来自英文到简体中文的 15 条试跑语料、45 份候选译文及 180 组人机配对评分，各组合样本有限。后续可扩充高风险与分歧样本，引入多名人工评审及独立验证集，开展分层一致率、误判情况与人工复核量的数据验证。
