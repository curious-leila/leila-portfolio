只在需要外部事实的地方使用 Agent

不是每个质量问题都需要检索。对于术语是否符合官方规范这类无法仅靠文本判断的问题，才启动查证；其余判断沿既定流程完成，让额外成本对应明确的证据需求。

找到资料，不等于可以放行

查证器负责找证据，独立判断环节根据合格证据复评，最终分流由可靠性策略决定。取证、判断与放行分开，避免模型用自己的检索结果直接为自己背书；证据不足或冲突时交给人工。

4 次 → 1 次：先明确谁有权停止

同一历史案例在证据已充分后仍继续检索，暴露的是停止权归属问题。将充分条件交给规则层后，满足条件就停止。这个案例证明机制可以收敛，不代表所有场景的平均提效。

当前边界

这是产品原型。静态回放用于查看真实决策过程，主动提交才调用在线服务；当前验证不能外推为生产收益或统计显著提升。

02项目经历

大模型译文审校可靠性评测

评测设计与产品策略2026.07–2026.08

量化译文审校可靠性边界，为前述 Agent 分流策略提供评测依据。

评测看板 ↗GitHub 仓库

大模型评测 / 人机双评 / 在线数据看板

背景

整体评分表现好，不代表高风险场景可以自动放行。为了给后续 Agent 划定权限边界，先评测模型在不同质量维度与内容风险下的审校可靠性。

主要工作

评测框架与语料设计

基于 MQM 定义术语、准确性、本地化、受众适配 4 个质量维度及四级严重度；构建营销 / 客服 / 界面文案 94 条可追溯双语语料，按误译后果标注高 / 中 / 低风险。

人机双评与可靠性定位

采用生成与评审分离设计，由 GPT-4o、Claude、Gemini 生成 45 份匿名译文，Qwen 与人工按统一标准独立评分，形成 180 次人机双评；整体一致率 95%（Gwet's AC1 = 0.947），按“4 维度 × 3 风险”拆分后定位“术语 × 高风险”一致率仅 11/18（61%），为唯一低于 90% 的组合。

Bad Case 复核与问题归因

逐条复核人机分歧，通过外部证据纠正 6 次 AI 无据术语判断，AI 反向发现人工漏检 3 处；据此发现高风险术语判断易以内部知识替代外部事实依据，推动 Agent 引入外部证据查证与证据门控。

评测结果转化为产品策略

将 12 格可靠性结果映射为人工介入规则，离线推演人工复核量约为 28/180（15.5%）；提炼高风险术语证据约束，支撑 Agent 三级分流与自动化权限设计。

口径说明：15.5% 是离线策略推演，不是线上业务收益。

95% 之后，还要看风险集中在哪里

整体平均值会掩盖局部问题。拆成“4 个质量维度 × 3 档内容风险”，才能把术语高风险这样的薄弱组合单独识别出来。内容风险描述出错的后果，质量判断描述实际错误，两者需要分开。

人工评分也需要接受证据复核

人工与模型都可能漏判。对分歧查证、记录改判依据，比默认任意一方正确更有价值。评测终点是把可靠性转化为自动化权限；后续 Agent 再结合当前判断、证据状态与异常条件做分流。

当前边界

94 条是语料库规模，其中 15 条进入试跑，形成 45 份译文与 180 次维度判断。结果只支持当前样本与方法，不代表跨场景可靠性；离线策略推演也不能替代线上验证。
